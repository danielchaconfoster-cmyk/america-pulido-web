## 🛠️ 2. Ecosistema de Trabajo & Conexión con Meta (Facebook / Instagram / Ads)

### ¿Tenemos acceso directo vía MCP / API a Meta Ads o publicaciones?
- **Estado Actual de MCP**: El entorno dispone de herramientas activas para **GitHub, Canva, Stitch UI y Supabase**. **No existe un plugin MCP oficial de Meta para publicar en directo a las API de Facebook/Instagram en este entorno.**
- **⚠️ RESTRICCIÓN DE SEGURIDAD CRÍTICA**:
  > **NUNCA usar automatizaciones por navegador (scripts tipo Playwright/Selenium) en las páginas de Facebook/Instagram**. Meta bloquea agresivamente las cuentas que detectan bots de navegador. Toda interacción debe ser manual o a través de la API Oficial con tokens otorgados.

### Flujo de Trabajo Recomendado para Operar:
1. **Publicación Orgánica / Programada**: Copiar y pegar estos 18 posts utilizando la herramienta gratuita oficial **Meta Business Suite** (`business.facebook.com`), donde puedes programar publicaciones para Instagram y Facebook simultáneamente.
2. **Campaña Pagada (Meta Ads)**: Crear los anuncios desde **Meta Ads Manager** utilizando la estructura indicada en `CAMPANA_META_ADS.md` ($3.000 CLP/día Residencial | $1.500 CLP/día Industrial).
